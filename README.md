# 廓如亭 · 结构复原

颐和园廓如亭的**实时三维数字复原**：从零程序化生成八角重檐攒尖亭，
在浏览器里可环视、可拆解、可剖切、可查构件出处。

> 本项目是**程序化复原成果，不是文物测绘或激光扫描数据**。
> 尺寸依据公开史料与清工部《工程做法则例》推算，与实测可能存在偏差，
> 不应作为修缮或研究依据。界面内每处构件都标注了 H（史料交叉核实）/
> I（依营造则例推算）/ S（示意性构图）三级置信度。

## 快速开始

```bash
npm install          # 安装依赖（three 0.186.1 / vite 8.3.5 / @playwright/test 1.64.1）
npm run dev          # 本地开发（http://127.0.0.1:5173）
npm run build        # 构建静态产物到 dist/
npm test             # 纯函数单元测试（node:test）
npm run test:e2e     # 浏览器验收测试（Playwright，需先 build）
npm run serve        # 起本地静态服务预览 dist/
```

## 这个模型是怎么来的

全部几何由代码生成，**不加载任何外部模型或图片**：

| 构件 | 依据 | 置信度 |
|---|---|---|
| 八角平面、每面显三间 | 史料记载 | H |
| 内外三圈共 40 柱（24 圆柱 + 16 方柱） | 史料记载 | H |
| 柱高 4.29 m | 史料记载 | H |
| 八方月台边长 11.1 m | 史料记载 | H |
| 建筑投影边长 8.931 m（由建筑面积 384.95 ㎡ 等面积推算） | 推算 | H+I |
| 柱径 11:1、收分 7/1000、檐步五举 | 清工部《工程做法则例》 | I |
| 中/内圈柱半径、斗栱简化形制、彩画纹样 | 推算 | I |
| 东堤、十七孔桥、南湖岛、佛香阁方位距离 | 仅为构图 | S |

屋面为**青灰筒瓦**（按公开实景照片取色判定，非部分颐和园建筑惯用的黄琉璃）；
宝顶按素色处理。瓦垄是真实几何（半圆筒瓦实例化铺设），不是贴图冒充。

## 目录结构

```
index.html                  页面骨架
src/main.js                 启动入口（WebGL2 检测、失败兜底）
src/core/                   纯函数内核（无 DOM、无 three 依赖）
  geometry.js               几何合同、八边形、三圈柱位、屋面剖面曲线、几何自检
  state.js                  展厅状态机（reducer 纯函数）
  catalog.js                八个构件的讲解文案与置信度
src/scene/                  三维场景
  materials.js              程序化贴图与场景色板（固定种子 xorshift32）
  buildPavilion.js          亭体装配
  buildLandscape.js         东堤、湖面、十七孔桥、南湖岛、万寿山、植被
  roof.js                   上下重檐、瓦垄实例、垂脊、吻兽、宝顶
  carpentry.js              斗栱、枋檩、雀替、笼花板、藻井、匾额
  sky.js                    大气、IBL（PMREM）、太阳光照
  camera.js                 相机机位与约束
  interaction.js            热点拾取、分解、剖切
  renderer.js               渲染器挂载与生命周期
src/ui/                     界面
  tokens.css                唯一 UI 令牌（颜色只在这里定义）
  app.css                   布局与响应式
  icons.js                  单一内联 SVG 图标集
  components.js             C01–C10 组件
  app.js                    状态 ↔ 场景 ↔ DOM 单向流
  contrast.js               WCAG 对比度计算
tests/                      单元测试
e2e/                        Playwright 验收测试
tools/                      验收工具（对比度核查、几何校验、页面探针）
handoff/                    交接材料（简报 / 规划案 / 规格 / 策展笔记）
reports/                    执行报告与视觉自检截图
```

## 交互

- **左键拖动** 环绕、**滚轮** 缩放、**右键** 平移；画布聚焦后方向键也能操作，`R` 复位。
- 画面上的**八个标记**对应斗栱、彩画、藻井、匾额、柱网、月台、宝顶等构件，点击聚焦并展开说明。
- **分解结构**逐层拉开屋面与枋梁；**平面剖切**切开竖直面看内部柱网（展示内部结构，非测绘剖面）。
- **时刻与季节**联动光色、水色、树色与雾。

## 约束

- 页面运行阶段**零外部请求**：所有依赖本地打包，不引 CDN、不下载字体与贴图。
- 贴图全部由固定种子 `1752` 的 xorshift32 噪声在内存中生成，截图可复现。
- 首屏可交互目标 ≤ 2.5s；桌面 high 画质目标 ≥ 50 FPS。
