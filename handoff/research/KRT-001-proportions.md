# 策展底稿 KRT-001：清式营造比例（建模用）

供执行方在写参数化几何时直接引用。**不是本轮实现**，是核实过的比例依据。
来源：清工部《工程做法则例》通则（经百科条目转引）、百度百科「举架」「清代建筑」。

## 1. 清工部则例的核心比例（原文可核对）

| 项 | 规定 |
|---|---|
| 檐柱高 | **以面阔 8/10 定高** |
| 柱径 | **以面阔 7/100 定径**（原文「十分之七」，实际是百分之七） |
| 柱高 : 柱径 | **11 : 1** |
| 例 | 面阔一丈一尺（11 尺）→ 柱高八尺八寸（8.8 尺），径七寸七分（0.77 尺） |
| 收分（柱脚粗、柱头细） | 约为柱高 1/100；大式《营造算例》规定 **7/1000** |
| 上出（出檐） | 无斗栱小式：檐柱高 × 3/10；檐椽出头占 2 份、飞椽出头占 1 份 |
| 台明高 | 小式：柱高 1/5 或柱径 2 倍；**大式：台明上皮至挑尖梁下皮高 × 1/4** |
| 台明出沿（下出） | 小式：上出檐的 4/5 或柱径 2 倍；**大式：上出檐的 3/4** |
| 回水 | 上出 > 下出，其差即回水，保证檐水不浇台明 |
| 侧脚 / 生起 | 通则含此项，具体数值未在本次检索中取得，**建模取保守值并标注** |

## 2. 举架（清式；宋《营造法式》称举折，江南称提栈）

- 步架 = 相邻两檩中水平距离；举高/步架 = 「几举」。
- **清式：檐步架五举（0.50）；飞椽三五举（0.35）**。
- 其余各步举高视建筑大小与檩数递增：**大式依次为五举 → 六五举(0.65) → 七五举(0.75) → 九举(0.90)**。
- **城楼或亭子的脊步架坡度需酌情增陡，可达九五举乃至十举以上** ← 廓如亭是亭，直接适用。
- 举折（宋式，参考）：总进深 B 的 1/3～1/4 为举高 R，自脊而下每缝折 R/10、R/20、R/40…。

## 3. 换算到廓如亭（含一处自洽校验）

已知实测锚点：**柱高 4.29 m**、**建筑面积 384.95 ㎡**、**八角平面、每面显三间**。

推导：

1. **柱径** = 4.29 ÷ 11 ≈ **0.39 m**（与则例 11:1 一致）。
2. **收分** = 4.29 × 7/1000 ≈ **0.030 m**（柱头比柱脚小 3 cm）。
3. **明间面阔** = 柱高 ÷ 0.8 = 4.29 ÷ 0.8 ≈ **5.36 m**（则例「以面阔 8/10 定高」反推）。
4. **由面积反推外接圆半径**：八边形面积 = 2√2·R² → R² = 384.95 ÷ 2.828 ≈ 136.1 → R ≈ **11.67 m**，
   外接圆直径 ≈ **23.3 m**，单面宽 = 直径 × sin(22.5°) ≈ **17.9 m**。
5. **交叉校验**：17.9 m ÷ 3 间 ≈ 5.96 m/间，与第 3 条由柱高反推的明间面阔 5.36 m 同量级
   （差额来自次间酌减与周边廊）。**三条独立数据（面积、柱高、三间制）互相印证，说明平面尺寸落在 ~18 m 单面宽是可信的。**
6. **上出**：大式亭出檐深远，按檐柱高 × 3/10 得下限 1.29 m，实际取 **1.6–2.0 m**（配合 23.3 m 直径不至于压檐）。
7. **台明高**：大式取「台明上皮至挑尖梁下皮高 × 1/4」，具体数值需配合斗栱层数确定。
8. **举架步序（亭）**：檐步五举(0.50) → 六五举(0.65) → 七五举(0.75) → 脊步九五举(0.95)。
   飞椽三五举(0.35)。攒尖顶由八条垂脊对称放坡，不设正脊。

## 4. 建模时必须遵守的还原要点（来自廓如亭实测描述）

- 屋面为**重檐**：下檐与上檐各自成一套斗栱与举折。
- 下檐周围**雀替、笼花板**；**大木六檩**；**藻井天花**。
- **旋子大点金彩画**（1955 年后为墨线大点金）：彩画用色需查证，不许凭空配色。
- **十六吻兽**：八角攒尖的戗脊兽数量关系需查证（八条戗脊 × 每脊兽数 = 16 → 每脊 2 只）。
- **虎皮石台明 + 石角柱 + 垂带式台阶**；**八方月台边长 11.1 m**；**1 m 多高宇墙 + 四面木栅栏门**。
- 圆柱柱础为**八角形**，青石材质。

## 5. 仍需查证（不得留白）

屋面瓦色与剪边、宝顶形制、旋子彩画配色与金线比例、斗栱踩数与层数、侧脚/生起具体数值、
三圈柱网排布、十七孔桥与南湖岛/佛香阁的相对距离。
