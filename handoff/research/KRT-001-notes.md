## 第二轮补充（瓦色 / 匾额内容 / 十七孔桥 / 南湖岛）

### 匾额八块的具体内容与年代（新增，已核实）
来源：博雅地名网「颐和园廓如亭」、今日头条《廓如亭、十七孔桥和南湖岛》（含历史照片）、百科条目。

- 八块木匾中 **两块为乾隆御制诗**，分别作于**乾隆三十五年（1770）与乾隆三十六年（1771）**。
- 其余**六块为光绪朝大臣所撰**，内容**取自《文心雕龙》**，具体篇目为：
  **「原道」「证圣」「宗经」「史传」「神思」「通变」**（每篇一块，共六块）。
- 这六块光绪朝匾**钤有慈禧太后「三方佛爷宝」**（慈禧御览之宝 / 数点梅花天地心 / 和平仁厚与天地同意）。
- 「**廓如亭**」三字匾悬于**东面下层外檐**（一层面东外檐下）。
- 乾隆辛卯年（乾隆三十六年）那块题诗匾未见于颐和园两次出版的《乾隆题颐和园诗选》，诗文收录在后。

### 屋面瓦色（惯例已核实，廓如亭本体待证）
- 皇家园林颐和园**万寿山中轴线佛香阁**各层屋顶均为**黄琉璃瓦绿剪边**（多来源一致）。
- 清漪园**治镜阁**修缮黄册记「**瓦九样绿色箭边中心黄色琉璃脊瓦料**」，清代绘画多绘其「黄色琉璃瓦绿剪边」。
- 琉璃瓦等级：黄琉璃=皇室宫殿级；绿琉璃=亲王府邸级；青灰布瓦=平民级。
- **结论**：颐和园皇家建筑作「黄琉璃绿剪边」是强惯例，**但廓如亭本体的瓦色未找到权威文字直接记载** ——
  建模按「黄琉璃瓦 + 绿琉璃剪边」处理，并在页面注明为依园林惯例推定。

### 十七孔桥（远景建模用，已核实）
- 位于廓如亭西侧，**全长约 150 m，桥面宽约 8 m，高约 7 m**，**17 孔**，中间第 9 孔最大、向两端递减。
- 望柱石狮**544 只**（另有「540 余只」口径）；桥身南北两端各一对大型石刻靠山兽。
- 乾隆御题石刻：**「修蝀凌波」「灵鼍偃月」**。
- 冬至前后日落可见「金光穿洞」。

### 南湖岛（远景）
- 岛上两座主要建筑：**广润灵雨祠**（龙神庙，乾隆六十年（1795）加额）、**涵虚堂**（清漪园望蟾阁旧址，嘉庆朝改一层，1860 焚毁，光绪重建改名）。
- 涵虚堂悬**慈禧御笔「涵虚堂」**与**光绪御笔「晴川藻景」**匾。
- 南湖岛与治镜阁、藻鉴堂合称昆明湖「三岛」，对应蓬莱三岛意象。

### 廊檐细部（新增）
- 外柱间有**倒挂楣子、坐凳楣子**；外有矮墙（宇墙）围绕，**东南西北各有一出口**。

- 可用后处理模块已确认存在：`EffectComposer / RenderPass / UnrealBloomPass / OutputPass /

  环境光可用 `RoomEnvironment`（`three/addons/environments/RoomEnvironment.js`）。
- 关键 API 符号在 0.186.1 中确认存在：`outputColorSpace`、`SRGBColorSpace`、
  `AgXToneMapping` / `ACESFilmicToneMapping` / `NeutralToneMapping`、`ColorManagement`、

- **无头 Chromium**：WebGL2 可用，但 renderer 是 **SwiftShader 软件渲染**（maxTex 8192）；
  **headful Chrome** 走真实 GPU：`ANGLE Metal Renderer: Apple M5 Max`，maxTex 16384，
  支持各向异性过滤 → **视觉验收与帧率采样必须用 headful Chrome**，无头只做逻辑冒烟。
- 字体：本机**没有独立 `PingFang.ttc` 文件**，但 `Hiragino Sans GB` / `STHeiti` / `Songti` 均在。
  中文字体栈须写成具名栈（PingFang SC → Hiragino Sans GB → Microsoft YaHei → Noto Sans CJK SC → sans-serif），
  不写「系统默认」。
- **踩坑记录（实现期必须避开）**：若 `PMREMGenerator.fromScene()` 取自**空场景**，
  环境光为零，垂直于主光源的墙面会全黑并与深色背景融为一体，画面看起来像「模型塌了」。
  → IBL 必须来自**程序化天空**，不能来自空场景。

## 关键尺寸（决定性数据，已交叉验算）

来源：新浪博客《八方亭 廓如亭》「廓如亭坐落在颐和园东堤岸边，为八方重檐攒尖顶式样，
**每面显三间，明间面阔 3.2 米，两次间各面阔 1.6 米，对面面阔 15.5 米，角至角进深 16.7 米**」。

### 这组数字用八边形几何自洽验算（全部吻合，可放心用）

以单面面阔 s = 3.2 + 1.6 + 1.6 = **6.4 m**：

| 量 | 由 s=6.4 推出 | 原文记载 | 吻合 |
|---|---|---|---|
| 外接圆半径 R | s / (2·sin22.5°) = 6.4 / 0.76537 = **8.361 m** | — | — |
| 角至角（对角线） | 2R = **16.72 m** | 16.7 m | ✓ |
| 对面阔（两对边间距） | 2 × 内切半径 = 2 × s/(2·tan22.5°) = 2 × 7.725 = **15.45 m** | 15.5 m | ✓ |

→ **柱网外圈（檐柱圈）= 正八边形，外接圆半径 8.361 m，单面 6.4 m。**

### 由此解出的柱网（与「24 圆柱 + 16 方柱」完全对应）

每面 3 间需要该边 4 个柱位：角柱 —(1.6)— 柱 —(3.2 明间)— 柱 —(1.6)— 角柱。

- **外圈**：8 角柱 + 每面中间 2 根 = 8 × 4 − 8（角柱重复计）= **24 根圆柱** ✓
- **中圈**：8 根方柱（角柱位）
- **内圈**：8 根方柱（角柱位）
- 合计 24 + 8 + 8 = **40 柱** ✓（与实测完全一致）

→ 中圈/内圈半径按「同心正八边形」布置，具体值规划案定死；内圈承载藻井与宝顶，中圈承上檐。

### 建筑面积 384.95 ㎡ 的归属（推论）

外圈柱网八边形面积 = 2√2 × 8.361² = **197.7 ㎡**；而 384.95 ≈ 1.95 倍。
若把**外围廊**计入，外轮廓外接圆 R = √(384.95 / 2√2) = **11.667 m**（内切半径 10.76 m，单面 9.08 m），
即外廊外沿比柱网外扩约 3.3 m（半径向）。
**月台**（八边形，边长 11.1 m）外接圆 R = 11.1 / 0.76537 = **14.503 m**（内切半径 13.4 m），
比外廊外沿还外扩约 2.6 m —— 这正是「亭四周八方月台、环绕砌 1 米多高宇墙、四面各一座木栅栏门」的位置。

**处置**：以「实测面阔（3.2/1.6/6.4/15.5/16.7）+ 柱高 4.29 m + 月台边长 11.1 m」为**硬锚点**；
384.95 ㎡ 作为**外廊轮廓**的面积指标使用。规划案若给出不同归属，执行方按规划案并在本报告记录。

## 冲突与处理


- **建筑面积**：384.95 ㎡（百度百科、maigoo 一致）↔ 约 130–140 ㎡（部分旅游站点）。
  处置：简报以 384.95 ㎡ 为准，并要求页面注明口径差异。
- **柱数**：40 根（24 圆 + 16 方）↔ 42 根（maigoo 等）。
  处置：简报以「三圈共 40 柱」为主口径，建模按 40 柱三圈。
